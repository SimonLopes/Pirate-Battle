# Credits

## Game assets

All the images and sounds in `public/assets` come from the Jungle Gaming challenge repository:
[https://github.com/junglegaming/game-developer-challenge/tree/main/assets](https://github.com/junglegaming/game-developer-challenge/tree/main/assets)

They were provided for this challenge and I only use them here.

I made two files from them. The ship atlas in `public/assets/spritesheet/*.json` was converted from the original Starling XML to Pixi's JSON, and the images themselves are unchanged. The arena map in `public/assets/maps/arena.json` I built by hand from the original 64x64 tiles.

I didn't add any other images, sounds or fonts. The UI uses the system font.
